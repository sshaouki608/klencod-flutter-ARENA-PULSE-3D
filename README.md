# ARENA PULSE 3D

لعبة قتال سكاكين خيالية ثلاثية الأبعاد (منظور الشخص الثالث) — واجهة Flutter + محرك 3D حقيقي (WebGL) يعمل دون إنترنت.

## البنية التقنية (وما هي حدودها بصراحة)
- **Flutter/Dart**: الشاشات (البداية، اختيار الوضع، الإعدادات، الفوز/الخسارة، الإيقاف المؤقت) + عصا التحكم + الأزرار + أشرطة الصحة.
- **عالم 3D حقيقي**: محرك WebGL مكتوب داخل `assets/game/game.js` (مجسمات 3D، كاميرا منظور، إضاءة، ضباب، تصادمات، مقذوفات، AI). يعمل داخل WebView محليًا من ملفات الـ APK، بلا إنترنت ولا أذونات.
- لا يوجد Three.js/Unity: السبب أن مكتبات Flutter 3D الجاهزة غير مستقرة أو تحتاج قناة تجريبية. المحرك الحالي بسيط (مكعبات وكرات بإضاءة) لكنه 3D فعلي.
- **لم يُبنَ APK في بيئة الإنشاء** (لا إنترنت هناك). فحصتُ منطق اللعبة بمحاكاة وهمية ورياضيات الكاميرا فقط. أول بناء على GitHub هو الاختبار الحقيقي؛ إن فشل، أرسل لي سطر الخطأ من السجل.

## البناء من الهاتف (أسهل طريقة)
1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (Public أو Private) باسم arena-pulse.
2. في المستودع: **Add file → Upload files** ثم ارفع **ملف ZIP هذا كما هو** (`arena_pulse_3d.zip`) في جذر المستودع واضغط Commit.
3. **Add file → Create new file** واكتب في خانة الاسم: `.github/workflows/build.yml` والصق محتوى ملف `build.yml` (مرفق منفصلًا، أو افتحه من داخل الـ ZIP) واضغط Commit.
4. افتح تبويب **Actions** → سيعمل "Build ARENA PULSE 3D APK" تلقائيًا (5–10 دقائق). يمكنك تشغيله يدويًا عبر Run workflow.
5. عند النجاح (علامة خضراء) افتح التشغيل → أسفل الصفحة **Artifacts** → حمّل `ARENA-PULSE-3D-apk` (ملف ZIP يحوي `app-release.apk`) → فك الضغط وثبّت الـ APK (اسمح بالتثبيت من مصادر غير معروفة).

الـ workflow يفك الـ ZIP تلقائيًا ويولّد ملفات Android (`flutter create`) ثم يبني.

## التحكم
- العصا اليسرى: حركة (الكاميرا تتتبع الخصم تلقائيًا؛ للأعلى = نحو الخصم).
- KNIFE: رمي سكين (يستهدف الخصم). 
- زر القدرة (بنفسجي): قدرة كل 10 ثوانٍ؛ زر التبديل أعلاه يختار: DASH / SHIELD / PULSE / SLOW-MO.
- زر الإيقاف أعلى اليمين أو زر الرجوع.
